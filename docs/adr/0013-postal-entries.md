# ADR-0013: Postal entries

## Status

Accepted — 2026-09-21 (decision D13, Project Initialization Report Revision 2, Part A)

## Context

See Project Initialization Report Revision 2, decision D13.

## Decision

- Postal entries use the same ticket allocation engine.
- Initial assumption: one valid postal entry = one ticket.
- Postal tickets count toward the relevant ticket cap and are eligible for the main draw and for instant wins.
- Detailed postal-entry rules stay configurable, because legal requirements may vary.

## Consequences

- The rule values are OPEN O10: required fields, cutoff, whether email is mandatory, and entries per envelope.
